# SUMIBIKI 運営管理アプリ

Webマガジン「SUMIBIKI」（sumibiki.com）を1人で運営するための管理アプリです。運営マニュアルの各章を画面にしています。

## 使い方

`admin/index.html` をブラウザで開くだけで使えます。インストールやビルドはいりません。

- データはそのブラウザの保存領域（localStorage）に保存されます。別の端末やブラウザとは共有されません。
- **「設定・データ」→「JSONで書き出す」で定期的にバックアップしてください。** 30日以上書き出していないと、ダッシュボードに表示が出ます。
- 別の端末で使うときは、書き出したJSONを「JSONを読み込む」で取り込みます。

スマホからも使いたい場合は、`admin/` フォルダーをConoHa WINGのサブディレクトリ（例：`sumibiki.com/admin-xxxx/`）にアップロードし、ConoHa WINGの「アクセス制限（Basic認証）」をかけてください。データは各端末のブラウザに保存されるので、端末間でJSONをやり取りします。

## アーティファクト版

claude.ai のアーティファクトとして公開しています：https://claude.ai/artifact/NdPqJiidEhofck2f5fQGCh

- アーティファクト版では、データはクラウド（アーティファクトのデータベース）に保存されます。所有者だけが読み書きでき、どの端末から開いても同じデータが見られます。アイキャッチや図版の画像はアーティファクトの画像保存領域に置きます（ローカル版では縮小してブラウザに保存）。
- 公開用の1枚のHTMLは `node scripts/build-artifact.mjs` で `dist/sumibiki-admin.html` に作ります。

### サイト記事の取り込み

アーカイブには、sumibiki.com の公開記事を毎朝取り込んで表示します（スケジュールされたタスクが `scripts/sync-site.mjs` を実行）。ホテル記事の「記事URL」にサイトの記事URLを入れると、取り込んだ記事と結び付きます。手順は `scripts/SYNC.md`。

## 画面とマニュアルの対応

| 画面 | 内容 | マニュアル |
| --- | --- | --- |
| ダッシュボード | 次の号の残り日数・着手目安・記事の進み具合、今月の成果と目標、確認すること | 全体 |
| 号 | 季節ごとの号（テーマ・公開日・表紙）、号ごとの作業、記事の割り当て | 2章 |
| ホテル記事 | 制作フロー9段階、基本情報、見どころ・建築技法・出典・要確認、記事作成用Claudeへの依頼文（日英）、線図、予約リンク、公開前チェックリスト | 5章 |
| アーカイブ | 号ごとの記事一覧（アイキャッチ付き）と、サイトに近い記事ページ（日英切り替え、図版、出典） | 2・5章 |
| 線図 | 発注状況・権利の帰属・書面合意・元資料の許可の一覧、発注用リストのCSV書き出し | 6章 |
| アフィリエイト | 提携先と規約確認、月ごとの成果と目標比、予約リンクの月次確認 | 8章 |
| 集客・SNS | Instagram・X・Pinterestの投稿予定、記事タイトルのSEOチェック | 9章 |
| 用語集 | 日英の固有名詞・建築用語（英語版の依頼文に自動で入る） | 7章 |
| 定期作業 | 週次・月次・号ごとのチェックリスト（期間ごとに自動でリセット）、バックアップとセキュリティ | 10章 |
| 未決定事項 | 11章の項目と決定内容の記録 | 11章 |
| 設定・データ | 収益目標、準備期間、カラーコード・フォント、依頼文の文体・文字数、広告表記の文言、バックアップ | 1・3・4章 |

## 構成

```
admin/
  index.html   画面の枠
  style.css    白基調、色はサイトと同じ錆 #8c4a2a と明るい錆 #d9a27f の2色
  app.js       画面とデータ処理（外部ライブラリなし）
```
